## 👨‍💻 Sobre mim

Sou desenvolvedor **Full Stack**, com experiência na construção e modernização de sistemas corporativos, especialmente no **setor financeiro**. Trabalho com aplicações que integram **Java e Spring Boot** no back-end, **Node.js/TypeScript** como camada BFF e **Angular ou React** no front-end.

Tenho formação em **Sistemas de Informação** e sigo estudando **Engenharia de Computação**. Gosto de entender o funcionamento completo de uma solução: modelagem de dados, APIs, autenticação, mensageria, testes, observabilidade, infraestrutura e entrega.

Em projetos profissionais, atuei em sistemas de operações bancárias, financiamento de veículos e acompanhamento do consumo de recursos de nuvem. Nos meus projetos pessoais, exploro arquiteturas full stack, automação, boas práticas de engenharia e novas tecnologias.

- 🔧 **Foco principal:** Java, Spring Boot, APIs REST, SQL, Node.js, Angular e React.
- 🏗️ **Arquitetura:** BFF, integração entre serviços, JWT, mensageria e containers.
- ✅ **Qualidade:** testes automatizados, análise estática, cobertura e observabilidade.
- 🚀 **Entrega:** Docker, Jenkins, pipelines de CI/CD e estudos de GitOps.
- 📚 **Em evolução:** Python, Data Science, Machine Learning, Kubernetes e OpenShift.
- 🎓 **Compartilhamento:** interesse em ensinar programação e facilitar o aprendizado de iniciantes.

## 🔍 Como penso software

```text
Front-end (Angular / React)
          │
          ▼
     BFF (Node.js)
          │
          ▼
 API (Java / Spring Boot)
          ├──► Bancos de dados (SQL / NoSQL)
          ├──► Mensageria (RabbitMQ)
          └──► Integrações e serviços

 Testes • Segurança • Logs • Métricas • CI/CD
```

Não sigo uma arquitetura única para todos os problemas. Prefiro entender as necessidades de cada projeto e escolher ferramentas e padrões que façam sentido para o contexto.
